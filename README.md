# Full Stack AI Engineer Roadmap

> A structured, long-term learning reference for becoming a **Full Stack AI Engineer**—from software engineering foundations to production-grade AI systems.

## Curriculum V2

- **25 domains**
- **326 learning objectives**
- Covers engineering fundamentals, .NET, frontend, cloud, data/ML, GenAI, RAG, agents, production AI, system design, and portfolio delivery.

### Start here
1. Read [Curriculum V2 — Domain Index](curriculum/V2-Domain-Index.md).
2. Follow the domains in prerequisite order; use the checklist to track coverage.
3. Build projects and record evidence—not just completed videos.
4. Revisit gaps through coding practice, architecture exercises, and interview preparation.

## Learning principles

- **Learn fundamentals first:** don't skip a topic solely because it is familiar.
- **Practice actively:** implement, test, explain, and document.
- **Build evidence:** every major domain should lead to code, a design, a demo, or a written explanation.
- **Keep it current:** AI tooling and practices evolve; validate version-specific details against official documentation.

## Scope

This is a broad, role-aligned curriculum map—not an exhaustive encyclopedia or a promise of a particular job or salary. Use it to structure learning and expose knowledge gaps.
