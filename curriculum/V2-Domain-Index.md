# Curriculum V2 — Domain Index

**V2 scope:** 25 domains · 326 learning objectives

Use this index as a navigation map. The domain labels below describe the curriculum coverage; expand each into notes, labs, and evidence as you study.

## A. Professional Engineering Foundations
Professional practice, communication, debugging, documentation, estimation, code review, and engineering habits.

## B. Computer Science & Computer Systems
Computer architecture basics, operating systems, processes/threads, memory, networking, files, and runtime concepts.

## C. Programming & Language-Agnostic Foundations
Variables, types, control flow, functions, modularity, errors, data structures, algorithms, and programming paradigms.

## D. DSA & Problem Solving
Complexity, arrays/strings, linked structures, stacks/queues, trees, graphs, hashing, sorting/searching, recursion, and problem-solving patterns.

## E. C# Complete Language & Ecosystem
C# syntax and semantics, OOP, generics, delegates/events, LINQ, async/await, collections, exceptions, reflection, records, nullable references, and language evolution.

## F. .NET Runtime, Platform & Engineering
CLR, GC, assemblies, JIT, configuration, dependency injection, logging, hosting, diagnostics, performance, and .NET tooling.

## G. Software Design, Architecture & Domain Modeling
SOLID, design patterns, clean architecture, modular monoliths, DDD, CQRS, boundaries, maintainability, and architectural trade-offs.

## H. Databases, SQL & Data Engineering
Relational modeling, normalization, SQL, indexes, query plans, transactions, isolation, concurrency, migrations, EF Core, caching, and data pipelines.

## I. Backend, Web APIs & ASP.NET Core
HTTP, REST, ASP.NET Core, middleware, routing, validation, authentication/authorization, API versioning, OpenAPI, rate limiting, and API security.

## J. Distributed Systems, Messaging & Reliability
Service boundaries, messaging, queues, event-driven systems, consistency, idempotency, retries, circuit breakers, observability, and resilience.

## K. Frontend, Web Platform & TypeScript
HTML, CSS, browser fundamentals, DOM, JavaScript, TypeScript, accessibility, responsive design, forms, state, and browser networking.

## L. React & Next.js
React components, hooks, state, rendering, routing, data fetching, forms, testing, Next.js rendering modes, server/client components, and application structure.

## M. Testing, Quality & Secure SDLC
Unit/integration/contract/end-to-end testing, test doubles, automation, code quality, threat modeling, secure coding, dependency scanning, and review practices.

## N. Git, Linux, Containers, CI/CD & IaC
Git workflows, shell/Linux, Docker, container networking, pipelines, build/release, infrastructure as code, secrets, and deployment automation.

## O. Cloud, Platform & Operations (AWS + Azure)
Cloud fundamentals, IAM, networking, compute, storage, managed databases, serverless, containers, monitoring, cost, deployment, and cloud security.

## P. Python, Data Science & Math
Python fundamentals, environments, packages, typing, notebooks, numerical computing, statistics, linear algebra, probability, and data preparation.

## Q. ML & Deep Learning
ML workflows, supervised/unsupervised learning, feature engineering, evaluation, neural networks, embeddings, transformers, and model training concepts.

## R. LLM, Generative AI & Model Engineering
LLM concepts, tokens, context windows, prompting, structured outputs, tool calling, model selection, inference, latency/cost, and model APIs.

## S. RAG, Search & Knowledge Systems
Document ingestion, parsing, chunking, embeddings, vector search, hybrid retrieval, reranking, grounding, citations, retrieval evaluation, and freshness.

## T. AI Frameworks & .NET AI Integration
AI SDK concepts, model clients, abstractions, orchestration, streaming, structured data, tool integration, and AI capabilities in .NET applications.

## U. Agentic AI, Workflows & MCP
Agent loops, planning, tools, state, memory, workflow orchestration, human approval, MCP concepts, server/client integration, and safe tool execution.

## V. Production AI, Security, Evaluation & Governance
AI evaluation, traces, observability, guardrails, prompt injection, data privacy, access control, reliability, deployment, cost controls, governance, and incident response.

## W. Full-Stack Product Integration & UX
End-to-end AI product architecture, chat/streaming UX, upload workflows, authentication, persistence, feedback, accessibility, and product analytics.

## X. System Design, Architecture Interviews & Senior Readiness
Requirements, capacity estimates, APIs, data models, scaling, caching, queues, trade-offs, failure modes, architecture communication, and senior-level ownership.

## Y. Portfolio Capstones & Release Evidence
End-to-end capstones, deployment, documentation, tests, demos, architecture decision records, measurable outcomes, and portfolio presentation.

---

## Suggested progression
1. Foundations → Programming → DSA → C#/.NET
2. SQL/data → API/backend → architecture/distributed systems
3. Web platform → TypeScript → React/Next.js
4. Testing/security → Git/Linux/Docker/CI/CD → cloud
5. Python/math → ML → LLM engineering → RAG
6. AI frameworks → agents/MCP → production AI
7. Full-stack capstone → system design → interview and portfolio readiness

**Completion evidence:** code repository, tests, architecture diagram, README, demo, and a concise explanation of trade-offs for each major project.
