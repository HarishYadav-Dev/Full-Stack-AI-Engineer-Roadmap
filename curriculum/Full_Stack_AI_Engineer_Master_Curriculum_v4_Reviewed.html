Full Stack AI Engineer — Master Curriculum v4 (Reviewed)

Expanded topic inventory across software engineering, full-stack development, cloud, data, machine learning, LLMs, RAG, agents, MCP, production operations and senior engineering.

Designed for: experienced .NET engineer filling every foundational and advanced gap toward Senior AI Full Stack / GenAI Engineering.

Honest scope: No curriculum can guarantee “every topic” in a changing field. This version greatly expands the breadth and subtopic coverage, including adjacent engineering disciplines. It is a master checklist—not a textbook. Mark an item complete only after you can explain it, implement it, test it, debug it and discuss trade-offs. Use current official documentation for changing APIs/services.

Recommended learning order

  1. Foundations and CS → programming/DSA → C#/.NET → architecture/SQL/backend.
  2. Frontend → React/Next → testing → Git/Docker/CI/CD → cloud/platform.
  3. Python/math/data → ML → LLMs → RAG/search → frameworks → agents/MCP.
  4. Production AI/security/governance → system design → capstones → interviews.

Suggested routine: concept study, small implementation, tests/debugging, explanation/review. Build projects progressively; do not wait until the end to practice.

Progress is saved in this browser only (localStorage). Print or save a copy to keep a durable record.

Study plan (≈12–15 months at ~10 hrs/week)

Priority tags for an experienced .NET lead: Skim = audit only, close gaps; Deepen = known but incomplete; New = learn fully. Run the brand track (AD) in parallel from month 2.

  1. Weeks 1–4 — Gap audit: A–J Skim/Deepen (focus E async/concurrency, H SQL tuning, I security, J messaging). Build an AI “hello world” vertical slice (API + LLM + simple UI) now so motivation stays high.
  2. Months 2–4 — Python, math, ML core: AE, P, Q New; K–L New/Deepen; D light daily practice; start Capstone 1 reusing .NET strength; start publishing (AD).
  3. Months 4–7 — LLM, RAG, frameworks: R, S, T, AA New; M, N Deepen; deliver Capstone 2 with golden set and evals.
  4. Months 7–10 — Agents, MCP, production AI: U, V, W, Z New; deliver Capstone 3 with approval gates and audit.
  5. Months 10–13 — Platform, cloud, data: O, AB Deepen/New; deliver Capstone 4 (AI platform) and deploy with CI/CD, IaC and cost report.
  6. Months 13–15 — Architect readiness: X, AC, Y finalize; 5 design docs, mock interviews, certification exam, promotion evidence pack and first income-stream experiment (AD).

Monthly review: items checked, projects shipped, posts published, weak areas, next-month plan. Re-check vendor docs quarterly because model/API/standards names change quickly.

Review notes (v4)

Core 20% path (do these even if time runs short): AE Python bridge → FastAPI + Pydantic → LLM APIs with structured outputs and tool calling → RAG with a golden set and evals → agents + MCP with approval gates → observability, guardrails and prompt-injection defenses → deploy on Azure with CI/CD and a cost report → Capstones 2 and 3.

Section tags: Skim = audit and close gaps only; Deepen = you know it, fill holes; New = learn fully; Build = project work; Optional = only if a role demands it.

Mastery gate for every subject

  1. Explain the idea in simple terms and draw its flow.
  2. Implement a minimal example without copying.
  3. Write tests and cover edge/failure cases.
  4. Debug a deliberately broken version.
  5. Explain security, performance, cost and operational implications.
  6. Compare alternatives and justify a design choice.

Portfolio completion gate

Deliver four demonstrable systems: enterprise commerce; permission-aware RAG knowledge assistant; safe agentic operations workflow; and an AI platform with model routing, evaluation, telemetry, tenant isolation, usage/cost controls and deployment. Each needs architecture diagrams, ADRs, tests, CI/CD, security review, demo, runbook and limitations.
